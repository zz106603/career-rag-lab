# 백엔드 기술 역량

> 이 문서는 RAG 학습을 위해 작성한 합성 데이터이며 실제 인물이나 회사의 경력이 아니다.

## 주력 기술

- Python: FastAPI 기반 REST API, pytest 테스트, 데이터 처리 스크립트 작성
- Java: Java 17과 Spring Boot 기반 API 및 배치 처리
- 데이터 저장소: PostgreSQL의 트랜잭션과 인덱스 활용, Redis 캐시 구성
- 메시징: RabbitMQ 소비자, 재시도, dead-letter queue, 멱등 처리
- 개발 환경: Docker와 Docker Compose를 사용한 로컬 서비스 구성

## 설계 원칙

외부 서비스 호출부를 비즈니스 규칙과 분리해 단위 테스트가 가능하도록 구성한다. 비동기 처리에서는 메시지 전달 성공과 업무 처리 성공을 구분한다. 검색이나 분석 결과에는 원본 출처와 처리 시점 같은 메타데이터를 함께 보존한다.

## 테스트 경험

pytest와 JUnit을 사용해 단위 테스트를 작성한다. 외부 데이터베이스나 메시지 브로커가 필요한 검증은 통합 테스트로 분리하고, 기본 테스트가 로컬 서비스 상태에 의존하지 않도록 관리한다.
