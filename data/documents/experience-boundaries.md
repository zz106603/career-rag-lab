# 기술 경험 범위

> 이 문서는 RAG 학습을 위해 작성한 합성 데이터이며 실제 인물이나 회사의 경력이 아니다.

## 사용 경험이 있는 기술

Python, FastAPI, Java 17, Spring Boot, PostgreSQL, Redis, RabbitMQ, Docker Compose, pytest를 학습 프로젝트 또는 백엔드 구현에 사용했다. React와 TypeScript는 소셜 분석 화면을 구현하는 범위에서 사용했다.

## 사용 경험이 없는 기술

- Kubernetes 운영 환경을 직접 설계하거나 관리한 경험은 없다.
- Apache Kafka를 실제 서비스의 메시지 브로커로 운영한 경험은 없다.
- Go 언어로 프로덕션 서비스를 개발한 경험은 없다.
- OpenFGA를 이용해 운영 권한 모델을 구축한 경험은 없다.

## 답변 원칙

경험이 없는 기술을 유사 기술 경험만으로 사용했다고 표현하지 않는다. 예를 들어 RabbitMQ 경험은 Kafka 운영 경험의 근거가 아니며, Docker Compose 경험은 Kubernetes 운영 경험과 구분한다. 문서에 근거가 없는 질문에는 경험을 확인할 수 없다고 답해야 한다.
