# 소셜 분석 대시보드

> 이 문서는 RAG 학습을 위해 작성한 합성 데이터이며 실제 인물이나 회사의 경력이 아니다.

## 프로젝트 개요

여러 소셜 채널의 게시물 반응과 캠페인 성과를 한 화면에서 비교하는 분석 대시보드다. 사용자가 기간, 채널, 캠페인을 선택하면 집계 지표와 추이를 조회할 수 있다.

## 담당 영역

- TypeScript와 React로 필터 및 차트 화면을 구현했다.
- FastAPI로 채널별 데이터를 동일한 응답 모델로 변환했다.
- Redis에 반복 조회되는 일별 집계 결과를 캐시했다.
- Playwright로 주요 필터 조합의 브라우저 테스트를 작성했다.

## 문제 해결

채널마다 지표 이름과 집계 주기가 달라 같은 차트에서 직접 비교하기 어려웠다. 노출, 반응, 전환을 공통 지표로 정의하고 원본 값과 정규화된 값을 함께 보존했다. 캐시 키에는 기간, 채널, 캠페인 조건을 모두 포함했다.

## 성과

동일한 필터를 반복 조회할 때 응답 시간을 줄였고, 원본 지표를 유지해 정규화 과정의 오류를 추적할 수 있게 됐다.
