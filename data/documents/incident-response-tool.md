# 장애 대응 자동화 도구

> 이 문서는 RAG 학습을 위해 작성한 합성 데이터이며 실제 인물이나 회사의 경력이 아니다.

## 프로젝트 개요

서비스 경보를 수집하고 담당 팀에 전달하며 대응 기록을 남기는 내부 자동화 도구다. 중복 경보를 묶고 심각도에 따라 알림 경로를 선택하는 것이 목적이었다.

## 담당 영역

- Python으로 경보 정규화 및 중복 판별 규칙을 구현했다.
- FastAPI로 경보 수신 API와 처리 이력 조회 API를 제공했다.
- Docker Compose로 로컬 개발 환경을 표준화했다.
- pytest fixture를 사용해 외부 알림 서비스 없이 규칙을 검증했다.

## 문제 해결

같은 장애가 여러 모니터링 규칙에 걸리면서 담당자에게 반복 알림이 전송됐다. 서비스명, 오류 유형, 시간 구간을 조합한 fingerprint로 경보를 그룹화하고, 심각도가 높아질 때만 추가 알림을 보내도록 구성했다.

## 성과

반복 알림 수가 줄었고 하나의 장애에 대한 상태 변화와 대응 기록을 시간순으로 확인할 수 있게 됐다.
