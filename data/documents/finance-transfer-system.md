# 재무자료 전송 시스템

> 이 문서는 RAG 학습을 위해 작성한 합성 데이터이며 실제 인물이나 회사의 경력이 아니다.

## 프로젝트 개요

여러 회계 시스템에서 생성된 재무자료를 수집해 외부 기관으로 안전하게 전송하는 백엔드 시스템이다. 전송 순서 보장, 중복 방지, 실패 복구가 핵심 요구사항이었다.

## 담당 영역

- Java 17과 Spring Boot로 전송 API와 배치 작업을 구현했다.
- RabbitMQ에서 전송 메시지를 소비하고 처리 결과를 저장했다.
- 요청별 idempotency key를 사용해 중복 전송을 차단했다.
- 실패 메시지는 지수 백오프로 재시도하고 최종 실패 건은 별도 큐로 이동했다.

## 문제 해결

네트워크 타임아웃 뒤 송신 측은 실패로 판단했지만 수신 측에서는 처리가 완료되어 동일 자료가 두 번 전송되는 사례가 있었다. 자료 식별자와 대상 기관을 조합한 멱등성 키를 저장하고, 재시도 전에 기존 처리 결과를 조회하도록 변경했다.

## 성과

일시적인 장애에서도 자동 재시도가 가능해졌고 동일 자료의 중복 전송을 방지했다. 메시지 상태와 실패 사유를 분리해 운영자가 재처리 대상을 빠르게 찾을 수 있게 됐다.
