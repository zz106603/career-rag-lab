# 정밀 의료 데이터 플랫폼

> 이 문서는 RAG 학습을 위해 작성한 합성 데이터이며 실제 인물이나 회사의 경력이 아니다.

## 프로젝트 개요

유전체 분석 결과와 임상 지표를 연구자가 함께 조회할 수 있도록 만든 정밀 의료 데이터 플랫폼이다. 민감한 원본 데이터는 분석 영역에 격리하고, 외부 서비스에는 비식별화된 요약 정보만 전달하는 구조를 사용했다.

## 담당 영역

- Python과 FastAPI로 분석 작업 요청 API를 설계했다.
- PostgreSQL에 연구 과제, 분석 상태, 결과 메타데이터를 저장했다.
- 시간이 오래 걸리는 분석은 Celery 작업 큐로 분리했다.
- 결과 파일에는 접근 만료 시간을 적용하고 감사 로그를 남겼다.

## 문제 해결

대용량 분석 요청이 HTTP 처리 시간을 초과하는 문제가 있었다. API는 작업 식별자를 즉시 반환하고 백그라운드 작업자가 분석을 수행하도록 변경했다. 사용자는 작업 상태 API를 통해 `queued`, `running`, `completed`, `failed` 상태를 확인할 수 있게 됐다.

## 성과

긴 분석 작업과 사용자 요청 처리가 분리되어 API 응답 시간이 안정됐다. 실패한 작업의 원인과 재시도 기록을 감사 로그에서 추적할 수 있게 됐다.
